# Lab 5: ROS Package Creation

## Overview

This lab covers creating ROS2 packages, implementing publisher and subscriber nodes in C++, and using rosbag for topic recording and playback.

## Key Topics

- Creating ROS2 packages with `ros2 pkg create`
- Understanding package.xml and CMakeLists.txt
- Implementing publisher nodes
- Implementing subscriber nodes
- Building packages with colcon
- Using rosbag for topic recording and playback
- Practical assessment with live demo

## Practical Assessment

**Practical 1 (20%)**
- Individual work
- Live demo to instructor is compulsory
- Demo tasks: Task 1, Task 3, Task 4
- Late demo subject to penalty

## Demo Questions

Be prepared to answer:
- Difference between running turtlesim from different terminals
- What is git clone?
- When to run colcon build command?
- Topic name that talker is publishing
- Publisher and subscriber node names
- Command to view topic frequency
- Message type of the topic
- Examples of listener and talker nodes in robotic systems
