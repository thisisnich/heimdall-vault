## Summary

Tutorial on **digital modulation**: sketch ASK/FSK/PSK for bit string `011010`, bandwidth efficiency of BPSK/QPSK/256-QAM/1024-QAM/16FSK, compare 8PSK vs 8FSK, QPSK and π/4-QPSK vector diagrams, system figure of merit, analysis methods (time vs frequency domain), baseband filters, and **zero-ISI** (raised cosine / Nyquist).

## Questions

1. Draw time-domain modulated waveforms for `011010` using:
   - (a) Amplitude shift keying (ASK)
   - (b) Frequency shift keying (FSK)
   - (c) Phase shift keying (PSK)

2. Determine theoretical **bandwidth efficiency** of BPSK, QPSK, 256-QAM, 1024-QAM, and 16-FSK.

3. Calculate bandwidth efficiency of **8PSK** and **8FSK**. Which has better bandwidth efficiency?

4. Sketch vector diagrams and explain key characteristics for:
   - (i) QPSK
   - (ii) π/4 QPSK

5. State a **figure of merit** for overall digital communication system performance.

6. Name **two methods** of analysing digitally modulated signals.

7. Name **two types** of baseband filters widely used in digital comms.

8. Which filter type achieves **zero ISI**? Explain how zero ISI is achieved.
