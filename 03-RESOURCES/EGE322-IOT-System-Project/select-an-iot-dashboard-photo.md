# Choosing an IoT Dashboard

![[99-ATTACHMENTS/EGE322/Select an IOT Dashboard.png|Choosing an IoT Dashboard — platform comparison]]

## Summary

Reference chart from course materials comparing IoT dashboard platforms by category: **Educational & Maker**, **Open Source**, and **Industry & Enterprise**. ThingSpeak and Adafruit IO are starred as course favourites; Firebase is noted as a **backend for building your own** custom dashboard.

---

## Educational & Maker

| Platform | Remark |
|----------|--------|
| **ThingSpeak** ★ | Great for learning; simple graphs & MATLAB |
| **Adafruit IO** ★ | Easy with maker hardware; beginner-friendly |
| **Ubidots (STEM)** | Free tier for students; easy start |
| **Firebase** | Backend, not a dashboard — build your own custom UI |

## Open Source

| Platform | Remark |
|----------|--------|
| **ThingsBoard** | Powerful, full-featured; self-host for control |
| **Node-RED Dashboard** | Visual flow-based local UIs (e.g. Raspberry Pi) |
| **Grafana + InfluxDB** | Industry standard for custom visualization |
| **Home Assistant** | Top open-source home automation |

## Industry & Enterprise

| Platform | Remark |
|----------|--------|
| **TagoIO** | Polished commercial; strong for LoRaWAN |
| **AWS IoT Core** | Hyperscale cloud IoT services |
