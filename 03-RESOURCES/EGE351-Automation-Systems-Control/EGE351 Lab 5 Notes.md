# Lab 5: Combination Logic 3

## Overview

This lab focuses on PLC combination logic programming and counter applications. Students will write and test PLC programs for:
- Pusher system control with object counting
- Display light system with LED cycling
- Multi-stage LED activation with gantry control

## Key Concepts

- PLC combination logic
- Counter implementation
- Sequential control systems
- Timer-based operations
- Limit switch detection
- Pushbutton control (NO/NC)

## Lab Questions

1. Pusher system with 8-object counter and alert
2. Display light system with 4-LED cycle
3. Multi-stage LED activation (3/5/7 presses) with gantry control

## Equipment

- Programmable Logic Controller PLC FP7
- Input/Output devices
- Pusher cylinders
- LEDs (red, green, blue, amber)
- Pushbuttons (START/STOP/RESET)
- Limit switches (SW1, SW2)
