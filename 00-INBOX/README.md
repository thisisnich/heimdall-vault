# Inbox

Drop quick captures here or in `_drop/` for scripts.

**Agents:** Process weekly. Nothing stays >7 days. See [[AGENTS.md]].

- `_drop/` — PDFs, images, URLs, **Voice Memos `.txt` transcripts** (preferred over raw audio)
- `_processing/` — script output awaiting filing

## After ingest

| What | Where |
|------|--------|
| Original PDFs, `.py`, images | `99-ATTACHMENTS/<COURSE>/` |
| Inbox originals (archive) | `99-ATTACHMENTS/<COURSE>/_inbox-archive/` |
| Converted markdown | `03-RESOURCES/<module>/` |
| Assignments / ICAs | `01-PROJECTS/` |

There is no `00RAW` folder — use **attachments** for source files and link from notes.
