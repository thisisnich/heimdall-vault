# MQTT

## Definition

Lightweight pub/sub messaging protocol for IoT; broker-based; topics and QoS levels.

## In my courses

- [[03-RESOURCES/EGE322-IOT-System-Project/|EGE322 IoT System Project]]

## Flashcards

- **Q:** What does MQTT stand for?  
  **A:** Message Queuing Telemetry Transport (historical name; used as acronym).

- **Q:** Name three QoS levels.  
  **A:** 0 (at most once), 1 (at least once), 2 (exactly once).
