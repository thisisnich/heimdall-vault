# Lazy Obsidian Method - Workflow

> 🔄 **Karpathy LLM-Wiki Method:** Raw → Processed → Structured → Connected
> 🎯 **Goal:** Turn messy notes into useful AI second brain

---

## 📋 Core Workflow Stages

### Stage 1: Raw Capture
**Location:** [[Resources-RAW/inbox/|Inbox]]  
**Mentality:** Capture messy, don't overthink  
**Frequency:** Throughout the day

**What to Capture:**
- 💡 Ideas and insights
- 📝 Meeting notes
- 🔗 Web articles and clips
- 🎧 Voice memos
- 📱 Quick thoughts
- 📚 Reference materials

**Capture Rules:**
1. **Immediate:** Capture when inspiration strikes
2. **Minimal:** Basic formatting only
3. **Context:** Add source/date if obvious
4. **Move On:** Don't overthink categorization

---

### Stage 2: Processing
**Location:** [[02-DAILY/|Daily Notes]] → [[Areas/|Areas]]/[[Projects/|Projects]]  
**Mentality:** Sort, categorize, basic organization  
**Frequency:** Daily review + weekly deep processing

**Daily Processing (5-10 min):**
1. **Quick Triage:** Scan inbox for obvious items
2. **Easy Wins:** Move clearly categorized items
3. **Flag Important:** Mark items needing attention
4. **Clear Junk:** Delete obvious clutter

**Weekly Processing (30-60 min):**
1. **Deep Review:** Go through remaining inbox items
2. **Categorize:** Move to appropriate PARA locations
3. **Basic Synthesis:** Combine related items
4. **Connect:** Link to existing knowledge

---

### Stage 3: Structuring
**Location:** [[03-RESOURCES/|Course Resources]]/[[wiki.md|Knowledge Base]]  
**Mentality:** Create structured, reusable knowledge  
**Frequency:** During weekly processing + as needed

**Structuring Activities:**
1. **Synthesize:** Combine multiple sources into coherent notes
2. **Template:** Use consistent formats for similar content
3. **Organize:** Create hierarchical knowledge structures
4. **Standardize:** Apply consistent tagging and naming

**Quality Standards:**
- ✅ Clear purpose and context
- ✅ Properly structured and formatted
- ✅ Connected to related concepts
- ✅ Searchable and accessible

---

### Stage 4: Connecting
**Location:** Cross-linking throughout vault  
**Mentality:** Build knowledge network, create insights  
**Frequency:** Ongoing during structuring phase

**Connection Activities:**
1. **Bi-directional Links:** Create two-way connections
2. **Context Links:** Link to broader concepts
3. **Application Links:** Connect to practical uses
4. **Timeline Links:** Connect to historical/future items

**Connection Types:**
- **Hierarchical:** Parent-child relationships
- **Associative:** Related concepts
- **Sequential:** Process/flow relationships
- **Temporal:** Time-based connections

## 🔄 Daily Workflow Example

### Morning (5 min)
1. **Review Yesterday's Processing:** Check completion
2. **Set Today's Focus:** Identify key priorities
3. **Quick Inbox Scan:** Clear obvious items

### Throughout Day
1. **Capture:** Use inbox for all new inputs
2. **Quick Tag:** Only if categorization is obvious
3. **Continue:** Don't break flow for organization

### Evening (10 min)
1. **Inbox Review:** Process easy items
2. **Daily Note:** Capture key learnings
3. **Tomorrow Prep:** Set up next day's focus

---

## 📅 Weekly Workflow Example

### Friday Evening (60 min)
1. **Inbox Deep Dive:** Process remaining items
2. **Project Review:** Update project statuses
3. **Area Assessment:** Review ongoing responsibilities
4. **Knowledge Synthesis:** Create structured notes
5. **Connection Building:** Strengthen knowledge links
6. **Archive Management:** Move outdated items

### Weekly Review Questions
- **What was captured this week?**
- **What needs immediate attention?**
- **What can be synthesized into knowledge?**
- **What connections were discovered?**
- **What should be archived?**

## 🎯 Processing Decision Tree

### New Item in Inbox
```
Is it actionable?
├─ Yes → Has deadline?
│   ├─ Yes → Move to Projects
│   └─ No → Move to Areas
└─ No → Is it reference?
    ├─ Yes → Move to Resources
    └─ No → Delete or Archive
```

### Structuring Decision Tree
```
Is it complete enough to be useful?
├─ Yes → Can it be synthesized?
│   ├─ Yes → Create structured note
│   └─ No → Leave in Resources
└─ No → Mark for future processing
```

## 💡 Best Practices

### Mindset
- **Capture Messy:** Don't let perfect block capture
- **Process Regularly:** Small, consistent efforts
- **Build Gradually:** Knowledge compounds over time
- **Stay Flexible:** Adjust system as needed

### Habits
- **Daily Capture:** Make it automatic
- **Weekly Review:** Non-negotiable processing time
- **Connection Building:** Always link new knowledge
- **Quality Focus:** Better to have less, better content

### Common Pitfalls
- **Over-organizing:** Don't spend too much time on single items
- **Perfectionism:** Good enough is better than perfect
- **Inconsistent Processing:** Missed days create backlog
- **Isolated Knowledge:** Always connect to existing content
