## 🔄 Lazy Method Workflow

### Daily Capture
1. **Raw Input** → [[Resources-RAW/inbox/|Inbox]] (messy notes, clips, ideas)
2. **Quick Tag** → Basic categorization, don't overthink
3. **Move On** → Keep momentum, process later

### Weekly Processing
1. **Review Inbox** → Promote useful items to proper locations
2. **Update Projects** → Move completed items to Archive
3. **Refresh Areas** → Update ongoing responsibilities
4. **Organize Resources** → Structure reference materials

### Monthly Review
1. **Project Audit** → Check progress and deadlines
2. **Area Assessment** → Evaluate ongoing commitments
3. **Resource Curation** → Clean up and organize
4. **Archive Management** → Move outdated items
