# 📥 Inbox - Raw Capture

> 🎯 **Purpose:** Immediate capture without overthinking
> ⏰ **Processing:** Daily review, weekly organization
> 📋 **Rule:** Capture messy, organize later

---

## 🔄 Processing Workflow

### Daily Capture (Throughout the day)
**What to capture:**
- 💡 Ideas and insights
- 📝 Meeting notes
- 🔗 Web articles and links
- 🎧 Voice memos
- 📱 Quick thoughts
- 📚 Reference materials

**How to capture:**
1. **Quick Note:** Don't format, don't categorize
2. **Basic Tag:** Only if obvious (academic, personal, technical)
3. **Move On:** Don't overthink, keep momentum

### Daily Review (5-10 minutes, evening)
**Quick Triage:**
1. **Easy Wins:** Move obvious items to proper locations
2. **Flag Important:** Mark items needing attention
3. **Delete Junk:** Remove obvious clutter
4. **Leave Complex:** Save detailed processing for weekly

### Weekly Processing (30-60 minutes, weekend)
**Deep Organization:**
1. **Categorize:** Move to appropriate PARA locations
2. **Connect:** Link to existing knowledge
3. **Synthesize:** Create structured notes from raw material
4. **Archive:** Move outdated or completed items

## 🎯 Processing Guidelines

### Immediate Promotion Rules
**Move to Projects if:**
- Has specific deadline or outcome
- Requires active work
- Part of current goals

**Move to Areas if:**
- Ongoing responsibility
- Regular activity
- No specific end date

**Move to Resources if:**
- Reference material
- Information for future use
- Research or learning content

**Move to Archive if:**
- Completed or outdated
- No longer relevant
- Historical reference only

### Quality Check Before Promotion
**Good to Promote:**
- ✅ Clear purpose or context
- ✅ Complete enough to be useful
- ✅ Can be properly categorized
- ✅ Has potential future value

**Needs More Work:**
- ⚠️ Incomplete or unclear
- ⚠️ Missing context
- ⚠️ Requires synthesis
- ⚠️ Needs research or verification

## 💡 Tips for Effective Capture

### Do's
- ✅ Capture immediately when inspiration strikes
- ✅ Use minimal formatting initially
- ✅ Add basic context if obvious
- ✅ Include source information (URL, date, context)

### Don'ts
- ❌ Don't overthink categorization during capture
- ❌ Don't spend time formatting initially
- ❌ Don't ignore items because they're "messy"
- ❌ Don't let perfect be the enemy of good

### Best Practices
- 🎯 **One Idea Per Note:** Keep focused
- 🏷️ **Basic Tagging:** Only if immediately obvious
- 📎 **Include Sources:** Track where information came from
- ⏰ **Time-Stamp:** Add capture date for processing priority
